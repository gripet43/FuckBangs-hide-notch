# 更新日志

## 1.3.3 — 2026-11-02

**切换桌面时，圆角不再"慢半拍"。**

之前从全屏应用滑回桌面，圆角什么时候回来全看是哪个应用——从 Chrome 回来，得等滑动彻底停稳才出现；从 Safari 回来，滑到一半就回来了。现在两边一致，圆角跟着桌面一起滑进来。

顺带修好一处：如果你在系统设置里开了「全屏时始终显示菜单栏」，全屏检测现在能正确识别，不会再出现黑条压在全屏画面上的情况。

## 1.3.2 — 2026-10-29

**换了个能说清自己在干什么的图标。**

旧图标像"一块屏幕上多了个刘海"，现在是"屏幕顶部被一条黑填平"，一眼能看出软件做的事。状态栏图标也加重了，在一排系统图标里更好认。

## 1.3.1 — 2026-10-29

**设置更顺手。**

- 关掉总开关后，圆角相关设置自动变灰，不会出现"刘海还在、圆角却生效"的矛盾状态
- 圆角开关和半径滑块进了快捷面板，不用再开主界面
- 滑块下面多余的刻度线去掉了
- 名称统一：「屏幕圆角」改叫「模拟屏幕圆角」，「砍掉刘海」改叫「干掉刘海」

## 1.3.0 — 2026-10-29

**圆角改成"卡片"式的效果。**

状态栏保持整条黑、四角方正，下面的桌面像一张圆角卡片压在上面。上两角和下两角用同一条弧线，不再是"上面小、下面大"。

## 1.2.1 — 2026-10-29

**顶部弧线修圆了。** 上一版顶部两角黑压黑，弧线几乎看不出来；现在四个角度一样清楚。

## 1.2.0 — 2026-10-29

**四个角统一了。** 此前是"下面圆、上面方"，现在上下弧度一致；默认半径也从 32 调到 40，更接近系统窗口的观感。

## 1.1.0 — 2026-10-29

**新增「模拟屏幕圆角」。** 把屏幕四角的方角收圆，半径可在 8–48 之间调。

- 只作用于 MacBook 自带屏；外接显示器保持直角，更符合它本身的物理形态
- 圆角在窗口之下，全屏看视频、玩游戏都不受影响
- 顺带把应用名定为「干掉刘海」

## 1.0.0 — 2026-10-29

**第一个正式版本。**

- 顶部整条填成纯黑，刘海看不出来了；不动壁纸，随时可以关掉
- 三种打开方式：状态栏图标左键弹快捷面板、右键出菜单、程序坞图标进主界面
- 全屏应用、菜单栏自动隐藏时自动让位，退出后自动恢复
- 多显示器只对带刘海的屏生效，外接屏不受影响
- 切换分辨率自动适配；没有刘海的机器装了也不会有任何变化
- 深浅色外观自适应，窗口位置会记住，Esc 关闭
- 关掉最后一个入口时会先确认，避免把自己锁在外面；真关完了也能用 Spotlight 打开主界面

**已知限制**

- 未经 Apple 公证，首次打开需要手动允许一次
- 整屏截图会带上黑边（黑边是真实窗口）
