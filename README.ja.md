**ノッチを消す。** MacBook のメニューバーを一枚の黒で塗りつぶし、ノッチを黒い縁に溶け込ませる軽量な macOS メニューバーアプリです。**壁紙は一切変更しません。** オプションで画面四隅の角丸も。

![メニューバーが一枚の黒になり、下のデスクトップは角丸になる](docs/screenshot-1.jpg)

## なぜもう一つノッチアプリなのか

多くのノッチアプリは逆方向に進みます。ノッチを「ダイナミックアイランド」にして、音楽やタイマーを詰め込む。これは逆です。**ノッチを視界から消す**だけ。

壁紙を書き換える方式との違い:

- 壁紙はそのまま、**ダイナミック壁紙も動き続ける**
- ワンクリックで元通り
- 画面収録権限もアクセシビリティ権限も不要、ネットワーク通信なし

## 機能

- **メニューバーを純黒に** — ノッチが上辺に溶け込み、目に留まらなくなる
- **画面の角丸** — コンテンツ領域を一つの角丸長方形に。半径は 8〜48pt で調整可能
- **フルスクリーン対応** — 動画・ゲーム・発表では自動的に退き、終わると戻る
- **外部ディスプレイは対象外** — ノッチのある画面だけに作用。外部モニタは直角のまま
- **解像度に追従** — 「ノッチの下」スケーリングにも対応
- **スペース切替に追従** — 角丸はデスクトップと一緒にスライドイン
- **権限ゼロ・通信ゼロ**

## インストール

1. [Releases](../../releases/latest) から `FuckBangs-1.3.3.dmg` をダウンロード
2. **アプリケーション**フォルダへドラッグ
3. 初回起動は Gatekeeper に止められます（公証なし）。**システム設定 → プライバシーとセキュリティ → 「このまま開く」** で許可してください。

**要件:** macOS 13 Ventura 以上。ノッチ付きの MacBook（14/16インチ MacBook Pro、M2 以降の MacBook Air）。ノッチのない Mac でもインストールできますが効果はありません。

詳しい機能説明・ソースからのビルド・実装メモは [English README](README.md) をご覧ください。
